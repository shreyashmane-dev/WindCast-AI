# Reports

This folder stores outputs for the Short-Term Wind Power Forecasting project.

The project uses Kaggle-style wind power and weather datasets with these input features:

- Wind speed
- Wind direction
- Temperature
- Humidity
- Dewpoint
- Wind gust
- Actual time / timestamp
- Power output

Models compared:

- Linear Regression
- Random Forest
- XGBoost
- LSTM

Primary comparison metrics:

- MAE
- RMSE
- R2
- MAPE

Generated files such as `model_metrics.csv`, CSV prediction exports, and dashboard audit reports are written here.
